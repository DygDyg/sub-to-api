Пулы

              
В клиенте укажите pool/имя. Диалог держится на одной модели, пока остаток больше 5% и передан prompt_cache_key. Если модель ответила ошибкой до первого токена, пул пробует следующую, но не ту, в чьё окно не влезает уже заполненный контекст этого запроса.

Документация

            
OpenAI-совместимый адрес для других программ. Если ключ обязателен, передайте его в Authorization: Bearer … или x-api-key.

          

          

            /v1
            
          

          

            

              

                

                  
GETСписок моделей

                  

                    /v1/models
                    
                  

                  
Чат-модели: /v1/models. Изображения: /v1/models?capability=image. Видео: /v1/models?capability=video.

                

              

            

            

              

                

                  
POSTЗапрос к модели

                  

                    /v1/chat/completions
                    
                  

                  
JSON-ответ или поток SSE при "stream": true. Поддерживаются messages, лимиты токенов, reasoning_effort и function tools.

                

              

            

          

          

            

              

                

                  
POSTИзображение

                  

                    /v1/images/generations
                    
                  

                  
codex или grok. Тело: prompt, необязательно provider, size, quality.

                

              

            

            

              

                

                  
POSTВидео

                  

                    /v1/videos
                    
                  

                  
Только grok, 1–15 секунд. Ответ содержит id; готовность проверяется через GET /v1/videos/{id}.

                

              

            

          

          

            

              Пример
              
            

            
curl /v1/chat/completions

          

          

            

              

                

                  
GETКвоты подписок

                  

                    /api/usage
                    
                  

                  
Доступ как у страницы настроек, без API-ключа. Один ответ по всем подключённым провайдерам: план, аккаунты и окна лимитов. Сервер отдаёт кеш 5 минут; ?refresh=1 запрашивает заново и при ошибке оставляет последнюю удачную квоту.

                

              

            

          

          
Другие пути /v1 возвращают 404. Страницу настроек можно открыть только с этого компьютера, из локальной сети или из интернета — отдельно от API. Ключ настроек обязателен из интернета, а из локальной сети — если это включено. С этого компьютера ключ не спрашивается.
