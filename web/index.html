Выбор модели по сложности

                    
Когда включён хотя бы один режим, в пулах появляется условие «По сложности запроса». Уровень моделей (light, medium, heavy) задаётся во вкладке «Модели» или через API, см. «Документацию».

                  

                  

                    

                      

                        

                          
                          
                        

                        
Мгновенно и без расхода лимита: длина и объём контекста, код, инструменты, reasoning_effort, ключевые слова. Счёт не ниже порога heavy — heavy, не ниже порога medium — medium, иначе light.

                        

                          

                            
                            
                          

                          

                            
                            
                          

                        

                      

                    

                    

                      

                        

                          
                          
                        

                        
Перед запросом дешёвая модель отвечает одним словом. Точнее на коротких сложных вопросах, но добавляет задержку и тратит её лимит. При ошибке или таймауте используются эвристики.

                        

                          

                            
                            
                          

                          

                            
                            
                          

                        

                      

                    

                  

                  

                    

                    
                  

                

              

            

          

        


        

          

            

              
Пулы

              
В клиенте укажите pool/имя. Диалог держится на одной модели, пока остаток больше 5% и передан prompt_cache_key. Если модель ответила ошибкой до первого токена, пул пробует следующую, но не ту, в чьё окно не влезает уже заполненный контекст этого запроса.

Модели

              
Цены справа — публичный тариф API за 100K токенов. Это ориентир для сравнения; фактические цены могут отличаться. Подписка по ним отдельно не списывает.

Статистика

              
Токены по фактическим моделям и оценка доли текущего лимита.

            

            

              

                
                
              

              

                
                
              

            

          

          

          

          
Оценка по трафику шлюза: токены модели в текущем окне делятся на все наши токены этого провайдера и умножаются на занятый процент. Кеш — уже входящая часть входа; оценка лимита считает его вместе с остальным входом. Запросы в официальных приложениях сюда не входят. Старые запросы до этой правки в статистику не попадают, а кеш в ней копится только с этого учёта.

        


        

          

            
Документация

            
OpenAI-совместимый адрес для других программ. Подойдёт любой ключ из списка. Нужен ли он, зависит от адреса: только из интернета, ещё и из локальной сети или везде. Передайте его в Authorization: Bearer … или x-api-key.

          

          

            /v1
            
          

          

            

              

                
Стартовый промт для ИИ: уровни моделей

                

                  

                    
                    
                  

                  
                

              

              
Скопируйте и отдайте модели: она прочитает список моделей, расставит уровни light / medium / heavy и сохранит их одним запросом. По умолчанию ключи — плейсхолдеры, чтобы случайно не скопировать секрет. Реальные ключи подставляются только при заданном ключе настроек.

              

              
Уровень отдельного запроса можно задать вручную: заголовок x-complexity: light|medium|heavy или поле "complexity" в теле /v1/chat/completions. Чтобы пул выбирал модель по уровню, включите режим в «Настройках» и создайте пул с условием «По сложности запроса».

GETКвоты подписок

                  

                    /api/usage
                    
                  

                  
Доступ как у страницы настроек, без API-ключа. Один ответ по всем подключённым провайдерам: план, аккаунты и окна лимитов. Сервер отдаёт кеш 5 минут; ?refresh=1 запрашивает заново и при ошибке оставляет последнюю удачную квоту.

                

              

            

          

          

            

              
Вход в настройки

              
Добавьте к адресу страницы параметр settings и ключ настроек: ?settings=ключ.

              

                /
                
              

              
Как открыть настройки из интернета

              
    
                
  1. На вкладке «Настройки» задайте ключ настроек (кнопка «Новый ключ» создаст случайный) и сохраните.
    2. 
                
  2. Сервер должен слушать сеть, а не только этот компьютер: в «Сеть» или «Доступ к настройкам» выберите локальную сеть или интернет. При обоих «Только этот компьютер» снаружи до сервера не достучаться.
    3. 
                
  3. На роутере пробросьте порт сервера на этот компьютер и разрешите его в брандмауэре Windows.
    4. 
                
  4. Откройте http://внешний-адрес:порт/?settings=ключ — ссылка выше, замените в ней хост на внешний IP или домен.
    5. 
                
  5. Сервер запомнит ключ в cookie на 30 дней и уберёт его из адресной строки. Дальше страница открывается без параметра.
    6. 
              

              
Без ключа или с неверным ключом сервер на запросы из интернета не отвечает: соединение висит около 25 секунд и закрывается. Сканеры видят просто таймаут и не узнают, что тут что-то есть. Ключ работает, даже если доступ к настройкам ограничен этим компьютером или локальной сетью.

              
Ключ в ссылке передаётся открытым текстом по HTTP — не публикуйте её и смените ключ, если она утекла. Если сервер стоит за туннелем или прокси на этом же компьютере, внешние запросы выглядят локальными, и защита ключом не срабатывает.

            

          

          
Другие пути /v1 возвращают 404. Страницу настроек можно открыть только с этого компьютера, из локальной сети или из интернета — отдельно от API. Снаружи без параметра settings страница не отвечает. С этого компьютера ключ не спрашивается.

        

      

    

  

  
    

      
Ключ для входа

      
С этого адреса страница настроек открывается только с ключом.
